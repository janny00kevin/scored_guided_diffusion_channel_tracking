# Modal Domain Beamforming Simulation Framework

This project provides a **plug-and-play** simulation environment for evaluating beamforming performance in high-frequency (12 GHz / 38 GHz) antenna arrays. It supports the analysis of both **Perfect (Ideal)** and **Imperfect (Robust)** eigenbeam precoding.
